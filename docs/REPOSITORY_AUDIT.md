# Repository release audit

Release candidate: **v1.0.0**

## Checks completed

- All public directory and file names are in English.
- No participant identifiers or internal row-to-identifier mappings are included.
- No participant-level `.mat`, spreadsheet, individual lesion-mask, or participant-derived connectivity files are included.
- Personal absolute filesystem paths were removed from the public historical scripts and documentation.
- Python files were syntax-checked.
- Included NIfTI files were checked for the expected 91 × 109 × 91 geometry and group-level content.
- Frozen numerical summaries were cross-checked against the final analysis matrices available during revision.
- The NRS item-level workflow covers both the fully adjusted models and the lesion-size-only sensitivity models.
- Historical FSL cluster thresholds, 26-connectivity and 40-voxel extent were recovered and converted into scripted commands.
- Frozen cluster sizes and peak coordinates reproduce the archived terminal output.
- NeuroVault provenance and a direct downloader are included for the Kletenik cross-modal map.
- The analysis-to-script-to-output relationship is documented in `ANALYSIS_CROSSWALK.csv` and `PROTOCOL_COVERAGE.md`.
- A SHA-256 manifest is generated for every released file.

## Important boundaries

MATLAB and the restricted participant-level inputs were not available in the release-building environment. The modular MATLAB implementation was therefore structurally and numerically cross-checked rather than rerun end-to-end there.

The historical anosognosia p-value was not accompanied by a preserved null distribution. The repository includes a documented revised permutation workflow, but the manuscript should retain the historical p-value only after it is regenerated by that workflow.
