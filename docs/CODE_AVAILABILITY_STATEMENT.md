# Code availability statement

Analysis code supporting this study is publicly available at GitHub: https://github.com/beatriceannunziatamilano228/lnm-perceived-health-somatic-concern, with the version corresponding to this revision archived as release v1.1.0: https://github.com/beatriceannunziatamilano228/lnm-perceived-health-somatic-concern/releases/tag/v1.1.0.

The repository includes recovered and documented MATLAB analysis code, the anatomy-conditioned permutation analysis introduced during peer review, FSL cluster-localization procedures, non-identifiable group-level outputs, and documentation of the SimNIBS simulations. The upstream normative-connectome infrastructure used to generate the stimulation-target map is maintained separately by the Center for Brain Circuit Therapeutics and is not redistributed; the resulting group-level target-connectivity map is provided in the repository.
