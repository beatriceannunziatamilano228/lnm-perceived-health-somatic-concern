# Analysis inputs

Participant-level and participant-derived inputs are not distributed in this public release.

The validated code expects four MATLAB files:

- `Corbettaconnectivitymaps101.mat`
- `CorbettaSF02_controls.mat`
- `GrafmanmapsnoNaN.mat`
- `NBRwithoutNaN_NBR02column1.mat`

Access is governed by the institutions responsible for the two original cohorts. The public
release includes frozen, non-identifiable analysis outputs generated from the validated inputs.
