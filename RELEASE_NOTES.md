# Release v1.0.0 — publication-ready repository

This release provides the manuscript-facing MATLAB analysis code, peer-review Python analyses, non-identifiable group maps and frozen outputs.

Key additions in the publication-ready audit:

- all public directory and file names standardized in English;
- `matlab/clean` renamed to `matlab/manuscript_analysis`;
- reviewer Python analyses moved under `python/reviewer_analyses`;
- NRS item-level code expanded to include both fully adjusted and lesion-size-only maps;
- historical FSL cluster workflow converted into scripts with exact thresholds, 26-connectivity and 40-voxel extent;
- frozen cluster tables added and matched to archived terminal output;
- NeuroVault provenance/downloader added for the Kletenik cross-modal map;
- explicit observed and revised permutation comparison code added for the anosognosia control;
- protocol-coverage and manuscript-alignment audits updated.
