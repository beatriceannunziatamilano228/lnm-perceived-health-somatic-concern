# Frozen cluster-localization tables

These tables were reconstructed from the public group maps using the exact historical positive thresholds, 26-connectivity and the 40-voxel extent criterion documented in `cluster_localization/cluster_thresholds.tsv`. The Dataset 1, Dataset 2 and combined cluster sizes and peak coordinates match the archived FSL terminal output.

The tables report raw cluster geometry. Anatomical labels are probabilistic and should be obtained with the supplied Harvard-Oxford `atlasq` workflow and reviewed against the statistical maps.
