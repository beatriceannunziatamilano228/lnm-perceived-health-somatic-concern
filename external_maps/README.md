# External comparison maps

The manuscript compares the historical combined lesion-associated map with the cross-modal awareness/anosognosia map from:

Kletenik I, Gaudet K, Prasad S, Cohen AL, Fox MD. *Network Localization of Awareness in Visual and Motor Anosognosia*. Annals of Neurology. 2023;94:434–441. DOI: 10.1002/ana.26709.

The associated public maps are deposited in NeuroVault collection **13792**. The cross-modal map is NeuroVault image **795501** with persistent identifier:

`https://identifiers.org/neurovault.image:795501`

The NIfTI is not duplicated in this release. Use the supplied downloader to retrieve the authoritative file and its API metadata directly from NeuroVault:

```bash
python external_maps/download_neurovault_image.py --image-id 795501
```

For provenance and sensitivity checks, the same script can retrieve images 795500 and 795502 from the collection. The NeuroVault metadata should be retained alongside any downloaded image.

The repository does not claim that the historically reported `p = 0.93` has been independently regenerated. The observed correlation and a revised permutation p-value can be recomputed with `python/external_map_comparisons/compare_with_kletenik_anosognosia.py`. The final manuscript should report only a value generated by the documented workflow or otherwise describe the comparison as descriptive.
