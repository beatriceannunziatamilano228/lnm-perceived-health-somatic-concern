# Historical MATLAB working code

These files are recovered working scripts from the original analysis period.

- Personal absolute paths have been removed.
- The scripts are retained to document provenance and historical choices.
- They may rely on variables already present in the MATLAB workspace, local NIfTI helpers, lesion-mask directories, and restricted inputs.
- They are **not** presented as a self-contained or fully executable pipeline.
- The clean modular implementation is in `../clean/`.

Important historical details visible in these files include nominal sample-size weighting (`101` and `181`), Fisher transformation of the component maps in the combined-map working code, participant-level forward prediction, item-level NRS mapping, and the original Westfall-Young working implementation.
